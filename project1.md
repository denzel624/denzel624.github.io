## Project description

This project involved developing a full-stack web application as part of a three-person team for a fictional nonprofit hosting a 5k charity run. This website demonstrates my frontend and backend development skills, which are essential for cybersecurity. I worked alongside A'Myah Temple and Pablo Aguilar to finish this assignment. The website allows participants to register, log in, view race-day information, and access a private dashboard. It also includes an admin interface that can manage all registered runners. My main contributions included developing admin management features, runner profiles, backend API improvements, and a teammate lookup function. I used CSS when working on the admin interface design.

## How to run the program

To run the website, download the project from the GitHub repository and open it in Visual Studio Code. In the Frontend folder, run npm install followed by npm run dev. In the backend folder, run dotnet run.

## UI Design

The website includes a homepage with information about the charity 5k and links to register or learn more. Once registered, users can access their dashboard to view their race schedule, route map, teammates, and personal information. The admin dashboard displays registered runners and allows admins to manage user roles.
